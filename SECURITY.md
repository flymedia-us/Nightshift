# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Email [contact@flymedia.us](mailto:contact@flymedia.us) with the subject line **Nightshift security report**. Include a clear description, affected version, reproduction steps, and any suggested mitigation. Please do not include secrets, private browsing data, or proof-of-concept code that could harm other users.

We will acknowledge reports within five business days and work with you on a fix and disclosure timeline. Nightshift is a Safari extension; reports involving website access, extension storage, content-script behavior, code signing, or the companion app are all in scope.

## Supported versions

The current release is supported. Older releases are handled case by case; please include the exact version so we can assess whether an update is practical.
