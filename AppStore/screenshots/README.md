# Screenshot production plan

App Store Connect requires at least one Mac screenshot and accepts up to ten. Produce a consistent 2880 × 1800 pixel, 16:10 set with no alpha channel.

## Recommended launch set

1. **Dark mode, on your terms** — Safari showing a neutral demo article with Nightshift active and the popup set to Always Dark.
2. **Follows your Mac automatically** — the popup set to System beside macOS Appearance settings or a tasteful light/dark comparison using the same demo page.
3. **Your sites, your choice** — the per-site control disabled for one clearly identified demo domain.
4. **Simple Safari setup** — the Nightshift companion window beside Safari's Extensions settings.

Use a purpose-built local demo page so no personal tabs, bookmarks, history, accounts, notifications, or third-party trademarks appear. Capture a clean Safari profile at 2× scale, keep window geometry identical, and export final screenshots without transparency. Verify every caption against the shipping build; do not show functionality that is merely planned.

Keep source captures and layered compositions in private Fly Media storage. Upload optimized final files directly to App Store Connect; do not commit them to this repository.
